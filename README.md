# 🚀 블로팀 (Blog Team)

AI 전문가와 함께하는 블로그 콘텐츠 작성/분석 도구

## 📋 팀 구성원

### 네로 (Nero)
- **플랫폼**: 네이버 블로그
- **경력**: 10년차
- **구독자**: 200만명
- **특기**: 감성적이고 친근한 스토리텔링

### 티로 (Tiro)
- **플랫폼**: 티스토리
- **경력**: 12년차
- **구독자**: 150만명
- **특기**: 전문적이고 깊이있는 분석

### 링커 (Linker)
- **플랫폼**: 링크드인
- **경력**: 프로페셔널
- **추천**: 10만명
- **특기**: 비즈니스 중심 인사이트

## 🎯 주요 기능

### 1. 콘텐츠 작성
- 3명의 전문가 페르소나 선택
- 주제 입력 후 자동 생성
- 플랫폼별 최적화된 글 작성

### 2. 콘텐츠 분석
- SEO 점수 분석
- 가독성 평가
- 참여도 측정
- 구체적 개선 제안

## 🛠️ 기술 스택

- **Frontend**: React + Vite
- **Backend**: Express.js
- **AI**: Claude API (Anthropic)

## 🚀 시작하기

### 1. 패키지 설치
\`\`\`bash
npm install
\`\`\`

### 2. 환경 변수 설정
\`.env\` 파일에 Anthropic API 키 설정:
\`\`\`
ANTHROPIC_API_KEY=your_api_key_here
\`\`\`

### 3. 서버 실행
\`\`\`bash
# 백엔드 서버 (포트 3200)
npm run server

# 프론트엔드 (포트 5174)
npm run dev
\`\`\`

### 4. 브라우저에서 열기
\`\`\`
http://localhost:5174
\`\`\`

## 💡 사용 예시

### 콘텐츠 작성
1. 전문가 선택 (네로/티로/링커)
2. 주제 입력 (예: "AI를 활용한 생산성 향상")
3. "콘텐츠 생성" 클릭
4. 생성된 글 복사하여 사용

### 콘텐츠 분석
1. "콘텐츠 분석" 탭 선택
2. 분석할 글 입력
3. "분석하기" 클릭
4. SEO/가독성/참여도 점수 확인
