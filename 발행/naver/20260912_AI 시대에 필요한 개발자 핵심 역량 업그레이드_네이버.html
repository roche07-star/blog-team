"제 실력이 이미 낡았다는 걸 면접장에서 깨달았어요" - 8년차 개발자 민준님의 고백

지난달, 면접 결과를 기다리던 민준님께서 제게 전화를 주셨어요.

목소리가 떨리더라고요.

"로체님... 저 정말 열심히 준비했는데, 면접관님이 LLM 파인튜닝 경험을 물어보시더라고요. 저는... 그게 뭔지도 정확히 몰랐어요."


8년차 베테랑이 겪은 충격

민준님은 백엔드 개발자로 8년을 일하신 분이에요.

Java 스프링으로 수많은 프로젝트를 성공시켰고, 팀에서도 인정받는 실력자셨죠.

그런데 최근 이직 시장에 나오시면서 충격을 받으셨대요.

"요즘 개발자 채용공고는 제가 아는 단어가 절반도 안 돼요"

LangChain, Vector DB, RAG, Prompt Engineering...

이게 다 뭔지, 자신의 커리어에 얼마나 중요한지 감이 안 오시는 거예요.


"제가 뭘 먼저 배워야 할까요?"

솔직히 저도 막막했어요.

AI 기술이 너무 빠르게 발전하니까, 헤드헌터인 저도 따라가기 버겁더라고요 😅

그래서 민준님께 여쭤봤어요.

"백엔드 개발자로서 AI를 어느 수준까지 알아야 할까요? 전부 다 배우기엔 시간이 부족하잖아요."

민준님도 그게 제일 고민이라고 하셨어요.

무엇을 우선순위로 둬야 할지 모르겠다고.


우연히 발견한 솔루션

마침 제가 최근에 알게 된 jobizic이라는 서비스가 있었어요.

직무별로 AI 역량 요구 수준을 분석해서, 학습 우선순위를 알려주는 기능이 있더라고요.

"민준님, 이거 한번 써보세요. 백엔드 개발자한테 필요한 AI 스킬이 뭔지 정리해주더라고요!"

처음엔 반신반의하셨어요.

근데 직접 사용해보시고는 표정이 180도 달라지셨죠


민준님이 발견한 것들

jobizic에서 분석 결과를 보시고는, 민준님이 제게 이렇게 말씀하셨어요.

"로체님, 저 괜히 딥러닝부터 공부하려고 했어요. 근데 제 직무엔 API 통합이랑 데이터 파이프라인이 훨씬 중요하대요."

맞아요!

백엔드 개발자는 AI 모델을 직접 만들 필요는 없어요.

대신 이런 걸 잘해야 하죠:

LLM API 연동 및 최적화
OpenAI, Claude 같은 API를 효율적으로 사용하는 법

벡터 DB 활용
RAG 시스템 구축을 위한 데이터 저장/검색

프롬프트 엔지니어링 기초
개발자가 알아야 할 수준의 프롬프트 최적화

자동화 도구 활용
GitHub Copilot, Cursor 등으로 생산성 2배 높이기

민준님은 이걸 보시고 학습 방향을 완전히 바꾸셨어요.


3개월 후, 달라진 민준님

"3개월 전의 저랑 완전히 달라졌어요. 이제 AI 관련 질문이 나와도 떨리지 않아요."

그 말을 들으면서 제 마음도 뭉클했어요

10년 동안 수많은 개발자분들을 만나왔는데요.

요즘 가장 많이 듣는 고민이 바로 이거예요.

"AI 시대에 내 실력은 충분할까?"

솔직히 말씀드릴게요.

지금 당장 변화하지 않으면, 2~3년 후엔 정말 힘들어질 거예요.
