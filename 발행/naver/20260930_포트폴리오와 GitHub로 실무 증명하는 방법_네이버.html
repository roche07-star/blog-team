"제 GitHub, 이게 맞나요?" 떨리는 목소리로 물어보던 준호님 이야기

안녕하세요, 헤드헌터 로체입니다 😊

오늘은 제가 3개월 전 만났던 준호님 이야기를 들려드릴게요.
첫 상담 때, 준호님은 노트북 화면을 보여주시면서
"이게... 포트폴리오라고 할 수 있을까요?"라고 조심스럽게 물어보셨어요.

3년 차 개발자인데, 왜 떨어질까요?

준호님은 3년 차 백엔드 개발자셨어요.
회사에서 열심히 일했고, 실력도 있으셨죠.

그런데 이직 준비하면서 계속 서류에서 떨어지셨대요.

"로체님, 저 실력은 있는데...
그걸 어떻게 보여줘야 할지 모르겠어요."

준호님의 GitHub를 봤더니 문제가 보였어요.
커밋은 많은데, 뭘 했는지 알 수가 없었거든요 😢

README 하나로 달라진 반응

제가 준호님께 물어봤어요.
"이 프로젝트로 어떤 문제를 해결하셨어요?"

그랬더니 정말 대단한 이야기가 쏟아져 나왔어요!

결제 시스템 장애를 3시간 만에 복구한 이야기
API 응답속도를 70% 개선한 방법
레거시 코드를 리팩토링한 과정

"준호님, 이 이야기들이 다 포트폴리오예요!
GitHub README에 이렇게 정리해보세요."

jobizic과 함께한 3주간의 변화

그때 제가 최근에 발견한 서비스를 추천해드렸어요.

jobizic이라는 곳인데요,
포트폴리오와 GitHub 저장소를 분석해서
개선 포인트를 제안해주는 기능이 있더라고요

준호님이 처음에는 반신반의하셨어요.
"이런 걸로 달라질까요?"

그런데 3주 후, 준호님께 연락이 왔어요.

"로체님! 면접 제안이 세 곳에서 왔어요!"

채용담당자들이 본 것

준호님이 바꾼 건 단순했어요.

Before ❌
- 코드만 덩그러니 있는 GitHub
- "열심히 했습니다" 같은 추상적인 설명
- 프로젝트 제목만 나열된 포트폴리오

After ✅
- 문제 정의 → 해결 과정 → 결과가 명확한 README
- 구체적인 숫자와 지표 (응답속도 70% 개선 등)
- 기술 선택의 이유와 트레이드오프 고민 기록

jobizic의 분석 기능이 알려준 대로
"기술 스택"보다 "왜 이 기술을 선택했는지"를
설명하니까 반응이 확 달라졌다고 하셨어요.

면접장에서 들은 말

준호님이 면접 보고 오셔서 말씀하셨어요.

"면접관님이 제 GitHub를 진짜 꼼꼼히 보셨더라고요.
'이 부분 어떻게 해결하셨어요?'라고 물어보시길래
README에 적어둔 대로 설명드렸는데..."

"바로 고개를 끄덕이시면서
'실무 감각이 있으시네요'라고 하시더라고요 😭"

그 순간, 준호님 목소리가 떨리는 게 느껴졌어요.
저도 덩달아 울컥했답니다

오픈소스 기여도 시작하셨어요

요즘 준호님은 오픈소스 프로젝트에도 참여하고 계세요.

"포트폴리오 정리하면서
제가 뭘 잘하는지 알게 됐어요."

작은 버그 픽스부터 시작해서
이제는 문서 개선 작업도 하신대요.

그리고 이 경험들도 다시 포트폴리오에 쌓이고 있고요
