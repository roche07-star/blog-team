"포트폴리오 전부 Private이라 아무것도 안 보입니다"

실제 채용 팀장의 피드백입니다.
당신의 GitHub, 채용담당자가 열어볼 수나 있나요?

이력서에 "파이썬 능숙"이라 적었지만,
Private 저장소라 검증이 불가능합니다.

즉시 탈락하는 포트폴리오 실수 3가지

1. GitHub 저장소가 Private
"깃 레포 프라이빗으로 하면 잔디도 안 보이고 한 게 안 보이더라고요"
→ 최소 3~5개 대표 프로젝트는 Public으로 전환하세요

2. 포트폴리오 링크가 404 에러
"안 열리는 것들이 있더라고요. 404는 ㅠㅠ"
→ 제출 전 모든 링크를 다른 브라우저에서 직접 확인하세요

3. 기술 스택만 나열
"파이썬 썼다 하는데 제대로 쓴 건지, 헬로 월드만 했는지 검증이 어려움"
→ README에 실제 구현 코드와 기능을 명시하세요

실무 증명하는 포트폴리오 필수 체크

Public 저장소 전환: 민감정보는 .env로 분리
모든 링크 검증: 데모 사이트가 정상 작동하는지 확인
코드 증명: 주요 기능을 README에 스니펫과 함께 설명
성과 지표: "API 응답 2초 → 0.3초 개선" 같은 수치 포함

Tip: jobizic(jobizic.com)의 포트폴리오 분석으로
채용담당자 관점에서 즉시 개선 포인트를 확인하세요.

오늘 당장:
1. Private 저장소 → Public 전환
2. 모든 포트폴리오 링크 직접 클릭해보기
3. README에 '왜, 어떻게, 결과' 추가
