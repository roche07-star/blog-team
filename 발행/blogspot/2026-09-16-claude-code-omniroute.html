OmniRoute는 Claude Code와 여러 AI 모델 사이에 있는 중간 프로그램입니다.

🎯 핵심 기능: Combo

Combo는 순서대로 시도하는 모델 목록입니다:

  1. 1순위 모델 시도
  2. 실패 시 → 2순위 모델
  3. 실패 시 → 3순위 모델

자동으로 다음 모델로 넘어가서 작업이 끊기지 않습니다!

🚀 3단계 설정 가이드

Step 1: 설치

npm install -g omniroute

Step 2: 서버 실행

omniroute serve

서버가 http://localhost:20128에서 실행됩니다.

무료 모델 확인:

  • 대시보드: http://localhost:20128/dashboard
  • 무료 제공자: /dashboard/free-tiers
  • 사전 구성된 무료 모델 자동 포함

🔗 Claude Code 연결

.claude/settings.local.json 파일 생성:

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:20128",
    "ANTHROPIC_AUTH_TOKEN": "omniroute",
    "ANTHROPIC_MODEL": "auto/best-free"
  }
}

설정 설명:

  • ANTHROPIC_BASE_URL: OmniRoute 서버 (주의: /v1 없음)
  • ANTHROPIC_AUTH_TOKEN: 대시보드 API 키
  • ANTHROPIC_MODEL: 자동 무료 모델 선택

이제 Claude Code를 평소처럼 사용하면 됩니다!

예시:

"깔끔한 포트폴리오 웹사이트 만들어줘"

→ 뒤에서 OmniRoute가 알아서 모델을 관리합니다.

📊 효과 비교

항목 단일 모델 OmniRoute (5개 모델)
연속 작업 시간 ~30분 ~2.5시간
월 비용 $20 $0 (무료)
모델 전환 속도 - 0.5~1.2초

⚠️ 주의사항

1. 모델 품질 차이

  • Claude Opus: 코딩 품질 9/10
  • 무료 모델: 코딩 품질 6~7/10

→ 중요 작업은 유료 모델 우선, 일반 작업은 무료 모델 허용

2. API 키 관리

❌ 영상/블로그에 API 키 노출 금지
✅ .env 파일에 저장 + .gitignore 추가

3. 컨텍스트 길이

무료 모델은 8K~16K tokens 제한 있음
→ 긴 대화는 유료 모델 사용 권장

✅ 결론

OmniRoute는 "Claude를 무제한 무료로 쓴다"가 아니라,
"여러 AI 모델을 번갈아 써서 작업 범위를 넓힌다"는 개념입니다.

이런 분께 추천:
