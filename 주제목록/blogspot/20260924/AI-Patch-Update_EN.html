Emergency Security Patches Released: AI Coding Tools Face Critical Plugin4Shell Vulnerability

Major updates rolled out for Claude Code, Codex, and others as the industry races to fix the Plugin4Shell flaw affecting AI agents. Here's what you need to know and how to update immediately.

The cybersecurity community is on high alert. In mid-September 2026, security researchers disclosed Plugin4Shell, a critical vulnerability affecting multiple AI coding agents. Some tools have already patched the issue, while others remain exposed. If you're using these tools for development, you need to act fast.

This isn't a minor bug fix—it's a remote code execution (RCE) vulnerability that could compromise your development environment. We've broken down the status of each major tool, what versions to update to, and what to do if you can't patch immediately.

01

What Is Plugin4Shell?

Plugin4Shell is a critical vulnerability discovered in September 2026 affecting AI coding agents and their plugin ecosystems. The flaw allows attackers to execute arbitrary code on systems running vulnerable versions of these tools.

The attack vector runs through the plugin architecture—malicious actors can inject code through AI-generated responses, which the agents execute without proper validation. This means a compromised plugin or a crafted prompt could give attackers direct access to your machine.

Impact level: Critical. Any developer using these tools on production-connected machines should prioritize updates immediately.

Tool-by-Tool Patch Status (September 2026)

CLAUDE CODE

Claude Code | Status: Patched

Current Safe Version: 2.1.179 or later

Patch Date: Mid-September 2026

Anthropic responded quickly to Plugin4Shell. Claude Code has been patched, and the company released version 2.1.179 with the fix applied. Users running earlier versions are vulnerable.

Patched Status

  • Fix confirmed in official releases
  • Patch available immediately
  • Clear version guidance provided

Action Required

  • Must manually update
  • Versions before 2.1.179 are vulnerable
  • Check your current version

How to Check Your Version: In Claude Code settings, go to "About" and verify your version number. If it's below 2.1.179, update immediately.

CODEX

OpenAI Codex | Status: Patched

Current Safe Version: 0.146.0 or later

Patch Date: Mid-September 2026

OpenAI deployed a security fix for Codex addressing the Plugin4Shell vulnerability. Users who have auto-updates enabled should already be protected. However, if you've disabled automatic updates, you'll need to manually install version 0.146.0 or newer.

Patched Status

  • Auto-updates available
  • Clear patch communication
  • Patch rolled out quickly

Update Concerns

  • Manual update needed if auto-update disabled
  • Earlier versions remain vulnerable
  • Older API integrations may be affected

How to Check Your Version: Open the Codex CLI and run codex --version. Update using npm install -g codex@latest if your version is below 0.146.0.

GITHUB COPILOT

Current Status: Unpatched as of mid-September 2026

Expected Fix: Under investigation

Expected Actions

Step-by-Step Update Guide

For Claude Code Users

Step 1: Check your current version. Open Claude Code and navigate to Settings → About.

Step 2: If version is below 2.1.179, go to File → Check for Updates.

Step 3: If no update appears, manually download version 2.1.179 from the official Anthropic website.

Step 4: Restart Claude Code and verify the new version in About.

Step 5: Run a test code generation to confirm functionality is restored.

For Codex Users

Step 1: Check your Codex version by running codex --version in terminal.

Step 2: Update using npm: npm install -g codex@latest

Step 3: Verify the update: codex --version (should show 0.146.0 or higher)

Step 4: Clear your Codex cache: codex cache --clear

Step 5: Test with a sample code generation task.

For GitHub Copilot Users (No Patch Yet)

Immediate Mitigation: Until Microsoft releases a patch, implement these controls:

  • Disable Copilot suggestions on untrusted repositories
  • Run Copilot in a sandboxed environment if possible
  • Disable plugin execution for AI-generated code snippets
  • Review all Copilot suggestions before running them
  • Update VS Code to the latest version for other security fixes

Watch for Updates: Monitor GitHub's official security advisory page daily. Subscribe to Microsoft's security notifications to get patch alerts as soon as they're released.

If You Can't Update Immediately: Workarounds

Running Tools Offline

If you're unable to update to patched versions immediately, consider disconnecting affected tools from the internet when not in use. This prevents remote exploitation of the Plugin4Shell vulnerability.

How: Configure your IDE to disable cloud sync and plugin downloads for vulnerable tools. Work in offline mode until patches are applied.

Code Review Everything

Until your tools are patched, implement strict code review processes. Don't execute any code generated by AI tools without human review. This adds friction but closes the attack surface.

Sandbox Environments

Run AI-generated code in isolated virtual machines or containers. This prevents system compromise even if the Plugin4Shell vulnerability is exploited.

Switch Tools Temporarily

If your workflow allows, temporarily switch to patched alternatives. Claude Code and Codex are both safe as of September 2026. This might be the safest short-term solution if you're using GitHub Copilot.
