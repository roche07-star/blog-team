5초 vs 10초, 그 결정적 차이

민서님의 포트폴리오 (첫 버전)

30페이지 분량의 PDF에 모든 프로젝트를 시간순으로 나열했어요.
대학 졸업작품부터 최근 프로젝트까지 빠짐없이요.

결과: 3곳 지원, 3곳 모두 서류 탈락

문제가 뭐였을까요? 내용이 부실해서? 아니에요.
채용담당자가 찾는 걸 5초 안에 보여주지 못했기 때문이에요.

포트폴리오는 '맞춤 제안서'다

민서님과 같이 포트폴리오를 완전히 뜯어고쳤습니다.
지원하는 회사의 JD를 펼쳐놓고, 한 줄 한 줄 분석했어요.

JD 키워드 분석 결과:

  • ✓ React 18 기반 대규모 웹 서비스 경험
  • ✓ 성능 최적화 (LCP, FID 개선 경험)
  • ✓ 협업 경험 (디자이너, 백엔드 개발자)
  • ✓ TypeScript, Next.js 활용 능력

그리고 민서님의 프로젝트 중 이 키워드에 딱 맞는 2개를 골랐습니다.
30개 프로젝트 → 2개 프로젝트로 압축했어요.

변경 전

  • 30페이지 분량
  • 시간순 나열
  • 모든 프로젝트 포함
  • 기술 스택만 나열
  • 성과 없음

변경 후

  • 8페이지로 압축

2. 숫자로 말하는 성과
